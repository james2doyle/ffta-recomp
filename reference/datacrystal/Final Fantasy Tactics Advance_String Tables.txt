 Information 
 This is just some basic information on the string tables and a list of them. 
 These were ripped using a program and have no been touched manually. 
 There are some spacing errors; this is because there is a special spacing string which uses a custom width, which is just shown as a normal space. 
 There are also some weird parts in some strings, this is because I didn't know what what the character was, so it was just represented with a \hXX .
